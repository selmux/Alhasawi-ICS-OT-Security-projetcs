# ICS Security

**Industrial Control Systems (ICS) & Operational Technology (OT) Cybersecurity Projects**

A collection of open-source tools, research projects, scripts, resources, and practical cybersecurity initiatives focused on Industrial Control Systems (ICS) and Operational Technology (OT).

This repository aims to contribute to the global ICS/OT cybersecurity community by sharing technical knowledge, research, tools, and educational resources that support the security and resilience of industrial environments.

## Projects and Resources

### 1. ICS Security Wordlists

Dedicated username and password wordlists developed for ICS/OT security research and authorized security assessments.

The wordlists are updated periodically as new relevant entries are identified.

### 2. Gas/Cylinder MATLAB Model

A MATLAB-based simulation model co-developed during my doctoral research.

The files are available in the `model/` directory.

### 3. ICS Search Engine Dorks

A collection of search queries for identifying ICS/OT devices and technologies through internet-facing search engines.

**Shodan:** ABB, BACnet, Conpot, Fuel Tank, KNX, Moxa, OPC UA, Rockwell, Siemens, SpaceLynk, SpiderControl, Tekon, WAGO, Yokogawa.

**Censys:** ATG, BACnet, Citrix, CODESYS, DIGI, DNP3, EtherNet/IP, FINS, Fox, GE SRTP, IEC 60870-5-104, Modbus, PCWORX, PRO_CON_OS, S7, WDRPC.

These resources are intended for authorized security research and infrastructure exposure assessment.

### 4. Metasploit Modules for ICS

A collection of ICS-related Metasploit modules for security research, controlled testing, and training environments.

### 5. ICS Exploits and Exploit Database Resources

Research resources and files associated with industrial vulnerabilities and publicly documented exploitation techniques.

### 6. Wireshark Filters for ICS Protocols

A reference collection of Wireshark display filters for inspecting industrial network protocols and supporting packet-level forensic investigations.

### 7. ICSFile

A tool for searching and identifying file extensions associated with ICS/OT systems and industrial automation software.

### 8. ICSFinder

A network assessment utility designed to check common ICS-related ports on specified hosts in authorized environments.

### 9. Nmap ICS/OT Scripts

A collection of Nmap scripts relevant to industrial protocols, asset discovery, and authorized OT network security assessments.

### 10. ICS/OT Cybersecurity Learning Resources

A curated collection of books, tools, articles, research papers, and technical resources recommended for individuals interested in learning industrial cybersecurity.

### 11. ICS/OT Simulation & Testbed

Simulation and testbed resources for industrial cybersecurity research, protocol experimentation, training, and controlled security assessments.

### 12. OT Security Agent Skills

**[Explore OT Security Agent Skills](ot-security-agent-skills/)**

An open-source collection of reusable **AI Agent Skills for ICS/OT cybersecurity investigations, industrial protocol forensics, evidence normalization, and incident response**.

The project combines industrial protocol knowledge with Python-based analysis tools and AI-agent instructions to support structured, evidence-based investigations.

The current collection includes eight skills:

| Agent Skill | Focus |
|---|---|
| **Modbus Forensics** | Modbus TCP traffic analysis, PLC register operations, and coil manipulation |
| **BACnet Forensics** | BACnet/IP communications and building automation security investigations |
| **Siemens S7 Forensics** | S7comm traffic, PLC operations, and controller communications |
| **IEC-104 Forensics** | IEC 60870-5-104 communications, telemetry, and control commands |
| **OT Application Forensics** | Node-RED, Grafana, InfluxDB, and MariaDB artifact analysis |
| **OT Evidence Normalizer** | Converting supported forensic reports into standardized investigation evidence |
| **OT Process Analysis** | Interpreting industrial control activities and potential operational consequences |
| **Attack Chain Reconstruction** | Correlating evidence and reconstructing chronological IT-to-OT attack sequences |

Each skill includes agent instructions (`SKILL.md`), supporting Python tools, documentation, and automated tests.

The tools are designed primarily for **passive, offline analysis**, with support for Windows and Linux environments.

**Project status:** Experimental (v0.1.x). The tools are under development and require independent validation of forensic findings.

For installation, usage examples, and technical documentation, visit the [OT Security Agent Skills project](ot-security-agent-skills/).

## Responsible Use

The tools and resources in this repository are provided for educational purposes, cybersecurity research, and authorized security assessments.

Industrial environments are operationally sensitive. Active testing, vulnerability scanning, or exploitation should only be performed with appropriate authorization and consideration of operational safety.

Forensic findings generated by automated or AI-assisted tools should be independently verified before being used for operational or safety-critical decisions.
